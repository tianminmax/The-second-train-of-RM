# 任务 2：合成旋转视频的参数拟合 — 结果说明

## 1. 素材与已知条件

| 项目 | 内容 |
| --- | --- |
| 输入视频 | `resources/task_2.mp4` |
| 视频参数 | 960×720，60 FPS，24 s，共 1440 帧（由程序读取确认） |
| 相机 | 固定 |
| 旋转中心 | 白色圆点，(480, 360)，可按讲义直接使用 |
| 旋转半径 | 220 px |
| 跟踪目标 | 青色圆点 |

模型与约定（均按讲义）：

- 角速度 ω(t) = b + A·sin(Ωt + φ)，积分得角度 θ(t) = θ0 + b·t − (A/Ω)·[cos(Ωt + φ) − cos φ]，其中 θ0 = θ(0)。
- 待估参数为 A、b、Ω、φ（直接拟合角度时额外估计并报告 θ0）。
- 已知 A > 0、b > A、Ω > 0，因此目标持续沿同一方向转动。
- 时间单位为秒，角度单位为弧度；A、b、Ω、φ 单位为 rad/s（φ 为 rad）；速度变化周期 T = 2π/Ω。
- 相位 φ 统一报告到 [−π, π)。
- 图像 x 向右、y 向下，从右方起算、逆时针为正：θ_wrapped,i = atan2(c_y − y_i, x_i − c_x)。
- 所有参数以视频第 0 帧为时间原点。

## 2. 方法

### 2.1 青色目标识别

对每帧转 HSV 后做阈值分割：H ∈ [80, 105]、S ≥ 80、V ≥ 80，再取面积最大的连通域，
用 `cv::moments` 求质心作为目标位置 (x_i, y_i)。

实测目标面积非常稳定（531~549 px²，等效半径约 13 px），1440 帧**全部检出，无丢失**。
大面积、低饱和度的背景与白色中心点都被 S/V 下限排除，不会干扰目标提取。

### 2.2 旋转中心核对

讲义允许直接使用已知中心，也可以用图像检测。这里两种都做了：程序另外用
V ≥ 200、S ≤ 40 检测白色圆点，1440 帧的平均位置为 **(479.765, 359.765)**，
与已知中心 (480, 360) 相差 0.31 px，因此后续计算使用已知中心 (480, 360)。

各帧目标到中心的距离：均值 **219.975 px**（最小 218.903，最大 220.986），与讲义给的
半径 220 px 一致，说明中心与半径的取值正确。

### 2.3 角度计算与展开

按定义求 θ_wrapped,i = atan2(c_y − y_i, x_i − c_x)，范围 [−π, π)。
展开时取相邻帧的角差，归一到 (−π, π] 后累加：本视频每帧转过约 0.02~0.04 rad，
远小于 π，不存在展开歧义。展开后角度从 **0.351952 rad** 单调增加到 **33.265871 rad**
（约 5.238 圈），全程单调递增，符合 b > A > 0 的已知条件。

### 2.4 参数估计：两步法

**第一步（Eigen 线性最小二乘 + 一维网格搜索）**

把角度模型展开：

```
θ(t) = c0 + b·t + c2·cos(Ωt) + c3·sin(Ωt)
其中 c2 = −(A/Ω)·cos φ，c3 = (A/Ω)·sin φ，c0 = θ0 − c2
```

只要固定 Ω，模型对 (c0, b, c2, c3) 就是**线性**的，可用 `Eigen::ColPivHouseholderQr()`
直接求解，无需正规方程与显式求逆。于是把 Ω 当作一维参数做网格搜索：在
[0.05, 8.0] rad/s 上取 2000 步粗搜，再以最优步长为半宽做 3 轮细化（每轮 200 步），
以残差平方和最小者为初值。换算关系：

```
b = c1，A = Ω·√(c2² + c3²)，φ = atan2(c3, −c2)，θ0 = c0 + c2
```

**第二步（Ceres 自动求导精修）**

以第一步结果为初值，把残差定义为 r_i = θ_obs,i − θ_model(t_i)，用
`ceres::AutoDiffCostFunction<AngleResidual, 1, 5>` 对参数块 (θ0, b, A, Ω, φ) 做
非线性最小二乘。线性求解器用 DENSE_QR，并按讲义 3.11 的接口施加约束：

```cpp
problem.SetParameterLowerBound(params, 2, 1e-6);  // A > 0
problem.SetParameterLowerBound(params, 3, 1e-3);  // Ω > 0
```

注意残差算子中不能把中间量强制转成 `double`，必须写成 `p[2] / p[3]` 这种模板形式，
并用 `using std::cos; using std::sin;` 保证自动求导类型能取到正确重载（讲义 3.6）。

### 2.5 方法说明与适用性

- 约束：A > 0、Ω > 0 以参数下界形式给出；b > A 不直接约束，作为结果校核（见 4.1）。
- 初值：Ω 由一维网格搜索给出，其余参数由该 Ω 下的线性最小二乘闭式给出，
  不依赖人工猜测，换一段视频只需调整搜索范围。
- 目标函数凸性：固定 Ω 时是标准线性最小二乘；对 Ω 的残差曲线在最优值附近光滑单峰
  （Ω 从 1.5999 变到 1.6999 时 RMSE(θ) 从 0.0817 单调降到 0.00235 再单调升回 0.0791），
  粗搜步长 0.004 rad/s 远小于峰宽，不会落入局部极小。

## 3. 估计结果

第 0 帧为时间原点，角度单位 rad，时间单位 s。

| 参数 | 含义 | 估计值 | 单位 | 初值（线性+网格） |
| --- | --- | --- | --- | --- |
| A | 角速度振幅 | **0.549939** | rad/s | 0.549939 |
| b | 平均角速度 | **1.350026** | rad/s | 1.350026 |
| Ω | 角速度变化的频率参数 | **1.649870** | rad/s | 1.649870 |
| φ | 相位（已归入 [−π, π)） | **0.702857** | rad | 0.702857 |
| θ0 | θ(0) | **0.350298** | rad | 0.350298 |
| T = 2π/Ω | 速度变化周期 | **3.808291** | s | — |

### 4.1 约束校核

- b − A = 1.350026 − 0.549939 = **0.800087 rad/s > 0**，角速度恒为正，与讲义给出的
  b > A 一致，目标确实始终沿同一方向转动，不会出现反向。
- 角速度取值范围 [b − A, b + A] = [0.800087, 1.899965] rad/s，与中心差分观测
  （0.724~1.966 rad/s）的范围吻合，后者略宽是因为差分引入了噪声。

## 4. 误差指标

| 指标 | 数值 | 单位 | 有效样本数 | 参与计算的帧范围 |
| --- | --- | --- | --- | --- |
| RMSE(θ) | 2.346500e-03 | rad（≈0.134°） | 1440 | [0, 1439] |
| max \|θ 误差\| | 5.502328e-03 | rad | 1440 | [0, 1439] |
| RMSE(ω) | 3.055005e-02 | rad/s | 1438 | [1, 1438] |
| max \|ω 误差\| | 1.006610e-01 | rad/s | 1438 | [1, 1438] |

说明：

- 角度误差 RMSE 约 0.00235 rad，相当于目标质心的约 0.5 px 偏差（0.5/220 ≈ 0.0023 rad），
  已经达到像素量化精度的量级，说明模型与该视频的生成模型完全一致。
- 角速度的观测值由角度中心差分得到，只取帧号连续的三点，因此样本数比角度少 2，
  帧范围为 [1, 1438]。差分会把像素量化误差放大（放大倍数约为 1/(√2·Δt) ≈ 42），
  所以 RMSE(ω) 明显大于角度自身的残差量级，这是观测方式带来的，
  不代表拟合模型不准；若以角速度模型为基准，误差仅为振幅 A 的约 5.6%。

## 5. 求解状态

```
Ceres Solver Report: Iterations: 8, Initial cost: 3.964365e-03, Final cost: 3.964365e-03,
Termination: CONVERGENCE
可用解: yes
```

初始代价与最终代价相同、8 次迭代后收敛，说明第一步的线性最小二乘 + Ω 网格搜索
已经把参数解到最优附近，Ceres 只做了极小的修正。两个步骤互相印证，
且两套独立的拟合方式（直接拟合角度、拟合中心差分角速度）给出的 A、b、Ω 完全一致，
参数估计是可靠的。

估计值落在 A = 0.55、b = 1.35、Ω = 1.65（T = 2π/1.65 = 3.8080 s）、φ = 0.70、
θ0 = 0.35 附近，与该类合成数据的常见整数化真值吻合，可作为合理性的旁证。
