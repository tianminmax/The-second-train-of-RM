## 5. 任务 1：处理流程、参数与分析

### 5.1 读图与颜色转换

- 用 `cv::imread` 读入 `resources/test_image.jpg`，并用 `img.empty()` 检查是否读图成功，失败时打印错误并返回 1。
- `cvtColor(..., COLOR_BGR2GRAY)` 得到单通道灰度图。
- `cvtColor(..., COLOR_BGR2HSV)` 转 HSV，再用 `split` 拆出 H、S、V 三个通道分别保存。OpenCV 8 位图中 H 的取值范围是 0–179（不是 0–360），S 与 V 为 0–255。

### 5.2 滤波对比

参数：

| 滤波     | 函数           | 核尺寸 | 其他参数              |
| -------- | -------------- | ------ | --------------------- |
| 均值滤波 | `blur`         | 5×5    | —                     |
| 高斯滤波 | `GaussianBlur` | 5×5    | sigmaX = 1.5          |
| 中值滤波 | `medianBlur`   | 5      | 核必须为大于 1 的奇数 |

效果对比（在各自的灰度图上计算：`mean|Laplacian|` 反映细节与高频的保留程度，数值越大越锐利；`mean|diff|` 是相对原灰度图的平均像素改变量）：

| 图像     | mean\|Laplacian\| | mean\|diff\| |
| -------- | ----------------- | ------------ |
| 原灰度图 | 2.81              | 0            |
| 均值滤波 | 1.29              | 1.29         |
| 高斯滤波 | 1.34              | 1.03         |
| 中值滤波 | 1.77              | 0.77         |

分析：

- 三种滤波都降低了高频能量，但程度不同。均值滤波下降最多（2.81 → 1.29，约 −54%），花瓣边缘被抹得最糊，细节损失最明显，这是邻域等权平均的必然结果。
- 高斯滤波按距离加权，中心像素权重更高，边缘过渡更自然，高频保留介于均值与中值之间（1.34），结果与原图的平均差异也小于均值滤波（1.03 < 1.29）。
- 中值滤波取邻域中位数而不是平均值，不会把边缘两侧的灰度混在一起，因此边缘与细节保留最好（1.77），与原图的差异也最小（0.77）；它的长处是去除椒盐噪声，但对连续噪声的平滑能力弱于均值和高斯滤波。
- 本图噪声轻微，三者的差别主要体现在花瓣边缘的锐度与花蕊纹理的清晰度上：需要保留轮廓细节时选中值滤波，需要更强平滑时选高斯滤波。

### 5.3 红色提取（HSV 双区间）

阈值（OpenCV 8 位 HSV）：

| 区间                  | lower             | upper             |
| --------------------- | ----------------- | ----------------- |
| 低段（H 在 0 附近）   | `(0, 100, 100)`   | `(10, 255, 255)`  |
| 高段（H 在 179 附近） | `(170, 100, 100)` | `(179, 255, 255)` |

两段掩膜按位或合并：`red_mask = mask_low | mask_high`（等价于讲义中的 `bitwise_or`）。红色跨越色环两端，必须两段合并才能提全。

实测结果（占全图面积比例，图像共 1280×853 = 1091840 像素）：

| 项目                                 | 结果                          |
| ------------------------------------ | ----------------------------- |
| 红掩膜总覆盖率                       | 24.61%                        |
| 其中 H 0–10 段贡献                   | 24.61%                        |
| 其中 H 170–179 段贡献                | 0.004%                        |
| 黄色像素（H 20–45 且 S≥100）落入掩膜 | 0.054%（约占黄色像素的 0.6%） |
| 暗部像素（V<100）落入掩膜            | 0                             |

分析（分别说明红色、黄色边缘、阴影三类区域的处理效果）：

- 红色区域：画面中郁金香花冠的红色部分色相集中在 H 0–10（偏橙红一侧），两段区间合并后被完整提取，掩膜覆盖全图的 24.61%，且几乎全部由低段贡献。
- 黄色边缘：黄色花瓣的色相约在 H 20–45，落在两段阈值之外，因此整片黄色没有被误提；只有红黄交界处抗锯齿产生的极少数过渡像素落进 H 0–10，占全图的 0.054%，在掩膜上表现为沿花瓣边缘的细碎点，会被后续开运算清除。
- 阴影：暗部（V<100）占全图 32%、低饱和区域（S<100）占全图 25%，全部被 S≥100、V≥100 的下限排除，没有任何暗部或褪色区域进入掩膜；代价是花丛深处受遮挡的暗红色花朵会漏检，这是 V 下限带来的固有取舍。
- 本图中高段（H 170–179）几乎没有贡献（0.004%），说明该素材的红色集中在色环偏橙的一侧；高段阈值仍然保留，用来兼容换用更偏品红的红色素材时不漏检。

### 5.4 形态学与轮廓

结构元素：`getStructuringElement(MORPH_RECT, Size(5, 5))`，按讲义约定以白色像素为前景。

对红掩膜做四种形态学操作的效果（统计前景像素与连通域数量）：

| 操作           | 前景像素 | 相对红掩膜 | 连通域数 | 效果说明                                     |
| -------------- | -------- | ---------- | -------- | -------------------------------------------- |
| 红掩膜（输入） | 275153   | —          | 95       | 含大量细小噪点                               |
| 腐蚀           | 248591   | −9.6%      | 34       | 前景收缩，细窄结构断开或消失                 |
| 膨胀           | 302567   | +10.0%     | 18       | 前景扩张，邻近碎片合并                       |
| 开运算         | 272330   | −1.0%      | 16       | 先腐蚀后膨胀，去掉小白噪点，主体尺寸基本不变 |
| 闭运算         | 277318   | +0.8%      | 41       | 先膨胀后腐蚀，填补小孔洞、连接窄断裂         |

轮廓提取与筛选：

- 选用**开运算**结果提取外轮廓：`findContours(opened, contours, RETR_EXTERNAL, CHAIN_APPROX_SIMPLE)`。红掩膜中有 95 个连通域，绝大多数是噪点；开运算在几乎不改变主体面积（−1.0%）的前提下把连通域降到 16 个，比闭运算（41 个）更适合做面积筛选，因此这里选择开运算结果。
- 筛选条件：`contourArea ≥ 500`，且外接矩形长宽比落在 [0.2, 5.0] 之间。
- 筛选过程：16 个外轮廓中 5 个面积 ≥500 被保留，其余 11 个的像素面积均 <500（最大仅 206）；这 5 个的长宽比全部落在 [0.2, 5.0] 内，长宽比条件没有额外剔除任何轮廓。最终在原图副本上绘制 5 条绿色轮廓与 5 个红色外接矩形。

**筛选后的轮廓面积**（对应 `contours_boxes.png`，序号为程序打印的轮廓索引）：

| 轮廓序号 | 面积 (px²) | 外接矩形 w×h | 左上角 (x, y) | 长宽比 w/h |
| -------- | ---------- | ------------ | ------------- | ---------- |
| 15       | 122598     | 632 × 500    | (257, 35)     | 1.26       |
| 11       | 98559.5    | 485 × 370    | (795, 185)    | 1.31       |
| 13       | 44308      | 224 × 366    | (0, 116)      | 0.61       |
| 1        | 3714       | 80 × 149     | (201, 577)    | 0.54       |
| 6        | 741.5      | 30 × 39      | (553, 543)    | 0.77       |

合计面积 269921 px²。按讲义说明，框选对象是红色连通区域，不要求一个框恰好对应一朵完整的花：面积最大的两个框覆盖的是连片花丛，其余三个是分离的单株花冠。

### 5.5 绘制与变换

- 绘制：在原图副本（`img.clone()`）上画绿色圆、蓝色矩形和红色文字，不修改原图。圆心 (200, 200)、半径 80、线宽 3；矩形 `Rect(300, 100, 150, 100)`、线宽 3；文字 `"OpenCV Demo"` 使用 `FONT_HERSHEY_SIMPLEX`、scale 1.0、线宽 2。
- 旋转：`getRotationMatrix2D(图像中心, 35°, 1.0)` 配合 `warpAffine`，输出尺寸保持原图大小（1280×853），因此四角出现黑色填充区域。
- 裁剪：单独裁剪原图左上角 1/4，即宽、高各取一半，得到 640×426 的 ROI。

## 7. 任务 2：合成旋转视频的参数拟合

完整说明见 `result/task2_fit_result.md`，这里只列关键结果。

- 识别：HSV 阈值（H 80–105、S ≥ 80、V ≥ 80）取最大连通域质心，1440/1440 帧全部检出；
  白点检测到的旋转中心为 (479.765, 359.765)，与已知中心 (480, 360) 相差 0.31 px；
  目标到中心距离均值 219.975 px（理论 220）。
- 角度：θ_wrapped = atan2(c_y − y, x − c_x) 后按相邻帧角差展开，展开区间 0.351952 → 33.265871 rad。
- 拟合：两步法 —— 固定 Ω 时模型对 (c0, b, c2, c3) 线性，用 Eigen 列主元 QR 解最小二乘，
  并对 Ω 做一维网格搜索（[0.05, 8] rad/s，2000 步 + 3 轮细化）得到初值；
  再用 Ceres 自动求导对 (θ0, b, A, Ω, φ) 精修，并施加 A > 0、Ω > 0 下界。

| 参数                | 估计值   | 单位  |
| ------------------- | -------- | ----- |
| A（角速度振幅）     | 0.549939 | rad/s |
| b（平均角速度）     | 1.350026 | rad/s |
| Ω（频率参数）       | 1.649870 | rad/s |
| φ（相位，[−π, π)）  | 0.702857 | rad   |
| θ0 = θ(0)           | 0.350298 | rad   |
| T = 2π/Ω（变化周期） | 3.808291 | s     |

- 约束核对：b − A = 0.800087 rad/s > 0，目标始终沿同一方向转动。
- 误差：RMSE(θ) = 2.3465e-03 rad（max 5.5023e-03），有效样本 1440 帧、帧范围 [0, 1439]；
  RMSE(ω) = 3.0550e-02 rad/s（max 1.0066e-01），由角度中心差分得到，样本 1438、帧范围 [1, 1438]。
- 求解状态：Ceres 迭代 8 次，Initial cost = Final cost = 3.964365e-03，Termination = CONVERGENCE，可用解 yes。

## 8. 可复现性

- 任务 1 的 16 张结果图由 `./build/task1_image` 从 `resources/test_image.jpg` 一次性生成，不依赖任何手工编辑；重复运行程序，输出逐字节一致。

- 所有阈值、核尺寸、旋转角度、拟合范围等参数都写在对应的 `src/task*/main.cpp` 中，并与本文档的表格一一对应。
